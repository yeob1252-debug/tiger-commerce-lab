# TIGER 맞춤 제안서 시각 리뉴얼안 V1

## 결론

현재 제안서의 업체별 전략·가격·실제 성과 데이터는 유지하고, 표현 방식만 홈페이지와 같은 검정·아이보리·골드 카드뉴스형 구조로 전환한다. 호랑이는 모든 화면에 반복하지 않고 제안의 시작, 신뢰 증명, 최종 행동을 결정하는 세 지점에만 배치한다.

## 현재 화면의 문제

| 구간 | 현재 문제 | 수정 방향 |
|---|---|---|
| HERO | 중앙 정렬 문구만 있어 업체별 제안의 첫인상이 약하다 | 왼쪽 맞춤 후킹, 오른쪽 실사 호랑이 얼굴의 2분할 HERO |
| 현황·기회 | 작은 칩과 텍스트 카드가 연속돼 보고서·PPT처럼 보인다 | 업체의 강점과 끊긴 고객 동선을 한 화면의 Before/After로 비교 |
| 고객 동선 | 단계가 작은 알약 형태로 보여 핵심 전략이 약하다 | 홈페이지와 같은 골드 진행선과 대형 단계 카드 |
| 콘텐츠 예시 | 텍스트 비중이 높아 실제 운영 결과를 상상하기 어렵다 | 숏폼·카드뉴스·Threads·블로그를 실제 콘텐츠 미리보기 형태로 표현 |
| 실제 성과 | 수치와 캡처는 정확하지만 시선 집중이 약하다 | 66.1K 숫자만 카운트하고 실제 캡처를 크게 배치 |
| 첫 30일·플랜 | 내용은 정확하지만 카드 높이와 정보 위계가 평면적이다 | 주차별 실행 타임라인과 홈페이지 플랜 디자인을 통일 |
| WHY TIGER | 대표자 사진만 있어 홈페이지의 TIGER 브랜드 세계관과 분리된다 | 대표자 경력은 유지하고 배경에 호랑이 눈·결을 낮은 농도로 결합 |

## 12개 섹션 수정 구조

| 섹션 | 핵심 화면 | 시각 구성 |
|---:|---|---|
| 01 | 업체 맞춤 HERO | 왼쪽 업체별 후킹·CTA, 오른쪽 실사 호랑이 얼굴. PC는 포인터 근접 시 눈과 얼굴이 밝아지고 모바일은 한 번만 자동 점등한다. |
| 02 | 이미 가진 강점 | 실제 매장·대표메뉴 이미지를 중심으로 `줄 서는 매장 / 대표메뉴 / 공식 채널 / 판매 기반`을 4개 큰 카드로 표현한다. |
| 03 | 현재 끊긴 지점 | `콘텐츠를 본다 → 검색하지 않는다`처럼 끊긴 행동과 개선 후 행동을 화면 좌우로 대비한다. |
| 04 | 왜 지금인가 | 큰 후킹 한 문장과 현재 기회를 보여주는 숫자·신호만 남기고 설명을 줄인다. |
| 05 | 고객 동선 | `SNS 발견 → 검색 → 방문 → 온라인구매 → 재구매`를 골드 진행선과 번짐 효과로 연결한다. |
| 06 | 콘텐츠 엔진 | HOOK·RETENTION·VALUE·CTA를 4개 대형 카드로 구성하고 스크롤에 따라 순차 활성화한다. |
| 07 | 업체 맞춤 콘텐츠 | 숏폼·카드뉴스·Threads·블로그 예시를 실제 게시물 미리보기처럼 보여준다. |
| 08 | 실제 성과 | 아이보리 배경에서 `66.1 K`와 반응 수치를 숫자만 애니메이션하고 실제 캡처는 원본 비율로 배치한다. 호랑이 눈의 얇은 골드 라인을 워터마크 수준으로만 사용한다. |
| 09 | 첫 30일 | WEEK 1~4를 PC 가로 타임라인, 모바일 세로 타임라인으로 전환한다. |
| 10 | 운영 플랜 | 홈페이지와 동일한 기간 토글·플랜 카드·추천 표시·VAT 고지를 사용한다. |
| 11 | WHY TIGER | 대표자 사진, 라이브커머스 경력, 통합운영 범위를 한 화면에 배치하고 우측 배경에 호랑이 얼굴 일부를 결합한다. |
| 12 | 최종 CTA | 어두운 호랑이 눈 배경 위에 업체별 최종 후킹과 상담 버튼을 배치한다. 눈빛은 CTA 진입 시 한 번만 밝아진다. |

## 반응형 기준

| 환경 | 적용 방식 |
|---|---|
| PC 1200px 이상 | HERO 2분할, 고객 동선·콘텐츠 엔진 가로 진행, 업체 이미지와 제안 문구 동시 노출 |
| Tablet 810~1199px | HERO 문구 위·호랑이 아래, 핵심 카드 2열, 진행 구조 2×2 또는 가로 스크롤 없는 줄바꿈 |
| Mobile 809px 이하 | 후킹 → 근거 → 이미지 → CTA의 1열 구조, 호랑이 자동 점등 1회, 고객 동선 세로 진행선 |

## 호랑이 적용 원칙

- 홈페이지의 실사 호랑이 자산을 재사용해 브랜드가 달라 보이지 않게 한다.
- 눈 아래에 별도 조명·원형 빛·가짜 눈을 만들지 않는다.
- 원본과 동일 구도의 밝은 레이어를 겹쳐 실제 눈과 얼굴만 자연스럽게 밝힌다.
- 제안서 전체에서 01·08·11~12 핵심 구간에만 사용해 업체 사진과 실제 증빙을 가리지 않는다.
- 업체별 HERO 문구와 매장 이미지는 데이터로 유지해 다른 제안서에도 같은 구조를 재사용한다.

## 변경하지 않는 항목

- 업체별 맞춤 카피와 분석 데이터
- 기장끝집 핵심 전략 `SNS → 검색 → 매장방문 → 온라인구매 → 재구매`
- 실제 조가네 사례 수치와 원본 캡처
- 6개월·12개월 가격, 제작 수량, VAT 고지
- 상담 연결과 기존 Proposal URL 구조

## 구현 순서

1. 공통 Proposal HERO에 호랑이 원본·밝은 레이어를 추가한다.
2. 12개 섹션의 기존 데이터를 유지한 채 카드뉴스형 레이아웃으로 교체한다.
3. 홈페이지의 골드 진행선·숫자 애니메이션·플랜 UI를 공통 컴포넌트처럼 재사용한다.
4. 기장끝집 제안서로 PC·Tablet·Mobile을 검증한다.
5. 다른 업체 Proposal 데이터에서도 문구 길이와 이미지가 깨지지 않는지 회귀검사한다.
6. 별도 Preview에서 승인받은 뒤 Production에 반영한다.
