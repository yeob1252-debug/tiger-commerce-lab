### ① 대시보드 (가로형 표: 1행 헤더 + 2행 값)
| 유튜브조회수 | 틱톡조회수 | 단골가두기방회원수 | 현재단계 |
|---|---|---|---|
| 268000 | 184000 | 320 | 2 |

- 1행에 항목 이름을, 2행에 실제 값을 가로로 나란히 입력하는 표 형식입니다(세로형 key-value 아님). 항목 순서는 상관없으며, 코드가 1행의 이름으로 값을 찾아 읽습니다.
- `현재단계`는 1~5 중 하나의 숫자만 입력하세요. 업무 로드맵 5단계(①브랜딩 작업 ②SNS 채널 오픈 및 콘텐츠 축적 ③SNS 댓글·구매문의 대응 ④라이브 방송 ⑤스마트스토어 판매라인 확장) 중 몇 번째가 "진행중"인지를 나타냅니다. 그보다 앞 단계는 자동으로 "완료", 뒤 단계는 "예정"으로 표시됩니다.
- 5단계의 이름·순서는 코드에 고정되어 있어 시트에서 이름을 바꿔도 반영되지 않습니다. 이름 자체를 바꾸고 싶으면 말씀해주세요.
- 값은 콤마(,)나 원(₩) 기호 없이 숫자만 입력해주세요. 텍스트로 입력되면 스코어카드에 0으로 표시될 수 있습니다.

- `날짜`는 `YYYY-MM-DD` 형식.
- `진행상황`은 반드시 `업무진행중` / `업무예정` / `이벤트` 셋 중 하나로 입력하세요 — 이 텍스트 값 그대로 대시보드 날짜 카드 색상에 자동 매칭됩니다(업무진행중=진한 오렌지, 업무예정=연한 베이지, 이벤트=보라). **시트에서 이 값만 바꾸면 코드 수정 없이 색이 바로 반영됩니다.**
- 대시보드에서 해당 날짜를 클릭하면 `콘텐츠주제`/`대표님협조사항`/`콘텐츠비용`이 팝업으로 표시됩니다. `대표님협조사항`이 비어 있으면 팝업에서 그 항목은 자동으로 생략됩니다.

## 2단계. Apps Script 붙여넣고 배포하기

1. 위 스프레드시트를 엽니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭.
3. 열린 편집기에서 기본으로 있는 `Code.gs` 내용을 전부 지우고, 이 저장소의 `.claude/apps-script/Code.gs` 파일 내용을 그대로 복사해서 붙여넣습니다.
4. 저장 (Ctrl+S 또는 디스크 아이콘).
5. 우측 상단 **배포 → 새 배포** 클릭.
6. 유형 선택에서 톱니바퀴 아이콘 클릭 → **웹 앱** 선택.
7. 설정:
   - **다음 사용자 권한으로 실행**: 나 (내 계정)
   - **액세스 권한이 있는 사용자**: 전체
8. **배포** 클릭 → 처음이면 Google이 권한 승인을 요청합니다. 본인 계정으로 로그인 → "고급" → "안전하지 않음(프로젝트명)으로 이동" → 허용까지 진행합니다.
9. 배포가 끝나면 **웹 앱 URL**이 나옵니다 (`https://script.google.com/macros/s/...../exec` 형태). 이 URL을 복사해서 저에게 알려주세요.

이후 제가 그 URL을 사이트 코드(`client.html`, `login.html`, `admin.html`)의 `APPS_SCRIPT_URL` 값에 넣고 배포하면 실제 데이터 연동이 완료됩니다.

> 시트 내용을 수정하고 나서 스크립트 코드 자체를 바꾼 경우에만 "배포 → 배포 관리 → 수정 → 새 버전"으로 다시 배포하면 됩니다. 시트의 값만 바꾸는 건(비밀번호, 매출 숫자 등) 다시 배포할 필요 없이 바로 반영됩니다.
